# TWE Brand Reference

## Identity

**TWE**  
**Technology. Work. Enterprise.**

Primary proposition:

> **Technology that works.**

TWE should feel like a product and workspace, not a corporate landing page.

## Colour

| Name | Hex | Use |
| --- | --- | --- |
| TWE Black | `#080808` | Logo, major text, navigation, CTAs |
| Pure White | `#FFFFFF` | Primary background |
| Valron Gold | `#C9A227` | Small highlights and active states |
| Carbon | `#1C1C1C` | Dark surfaces and code areas |
| Graphite | `#505050` | Secondary text |
| Muted Grey | `#6B6B6B` | Metadata |
| Warm Canvas | `#F7F6F2` | Editorial surfaces |
| Border Grey | `#E7E5E0` | Dividers and borders |

Recommended balance: **White 70% · Black 20% · Neutral greys 7% · Gold 3%**.

Gold should remain scarce.

## Typography

**Montserrat** for interface and editorial content.  
**JetBrains Mono** for code, terminal commands, APIs, SQL, paths and environment variables.

## Visual direction

Prefer real product interfaces, architecture diagrams, terminal/code screenshots, charts, device mockups, typography and useful photography.

Avoid generic AI imagery, glowing circuits, random holograms and decorative fake dashboards.
